# 第 1 集：没人教，它自己变强了

两个实验，都不用联网、不花钱，普通电脑几十秒到几分钟跑完。只依赖 Python 标准库和画图用的 matplotlib。

## 实验 A：井字棋自我对弈（[selfplay.py](selfplay.py)）

一个一开始什么都不会的程序，只知道规则和输赢。它自己跟自己下，每下完一盘，就顺着这盘棋倒着回想：哪些局面最后通向赢、哪些通向输，记到一张表里（时序差分学习，Sutton & Barto《强化学习》第 1 章的经典例子）。没有棋谱，没有人教。

每隔一段时间拉它去考试，考试时不学习：

- **考官 A**：随机乱下。
- **考官 B**：永远不犯错。它把井字棋全部 5,478 种合法局面穷举算透（minimax）。井字棋双方都不犯错的结果是和棋，所以对考官 B 最好的成绩就是「一盘不输」。

```bash
python3 selfplay.py      # 5 个随机种子，每个下 5 万盘
```

结果（5 个种子平均，每次考试先手、后手各 100 盘）：

| 已下盘数 | 对「永不犯错」输的比例 | 对「随机乱下」赢的比例 |
|---|---|---|
| 0 | 86.8% | 65.8% |
| 1,000 | 70.2% | 84.4% |
| 5,000 | 13.0% | 91.2% |
| 40,000 | 0.0% | 95.2% |
| 50,000 | 0.0% | 95.1% |

每个种子下完 5 万盘（含考试）大约 3.5 秒；最后记住了约 3,600 种局面。

输出：`results/curve.json`、`results/games.json`（视频里回放的对局）、`results/curve.png`。

## 实验 B：改进「自己怎么学」（[learn_to_learn.py](learn_to_learn.py)）

实验 A 里，学棋的方法是固定的。这里把 4 个设置交出去：学得多快、多爱瞎试、什么时候收起好奇心、没见过的局面先往好处想还是往坏处想。

1. 每一代拿当前最好的学法，做 7 个小变种，连同它自己一共 8 种。
2. 每种学法都从零学一遍井字棋，看要下多少盘才「学会」（对考官 B 连续两次考试 200 盘一盘不输）。
3. 学得最快的留下，传给下一代。

最后用 30 个没用过的随机种子，把每一代的最好学法重新比一遍，排除运气。

```bash
python3 learn_to_learn.py      # 几分钟
```

| 学法 | 平均要下多少盘才学会（30 次） |
|---|---|
| 原始学法 | 13,175 |
| 第 1 代 | 4,500 |
| 第 2 代 | 5,442 |
| 第 3 代 | 5,033 |
| 第 4–6 代 | 约 4,880 |

第 1 代就把盘数降到原来的三分之一左右，诀窍是「少瞎试，但对没见过的局面先往好处想」。之后再也改不动了：能拧的旋钮只有 4 个，很快到顶。

说明：挑选和变异是这个脚本（外层循环）做的，不是棋手自己想出来的。它是「递归自我改进」的玩具版：被改进的对象从「棋力」升了一级，变成「提升棋力的方法」。
